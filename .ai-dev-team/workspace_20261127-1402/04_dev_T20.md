## Command table (registry = docs/commands.md)
| Command | Behaviour |
|---|---|
| `/save-as [path]` | no path: Save As prompt; path: saves there (existing file → Replace prompt); folder / no file → error |
| `/reload` | `file.reload`; no file → error |
| `/term new`, `/term close` | `terminal.new` / `terminal.close`; close without a terminal → error |
| `/term right`, `/term bottom` | error "available after the terminal position feature" (T19 not built) |
| `/run <command>` | types the line + Enter into the active running terminal (new tab when none / exited), panel shown, focus on it; control chars refused |
| `/ai <tool>` | new terminal tab, tool line typed into its shell; missing tool → the shell's error |
| `/ws add <dir>` | `App::add_root` (W-1 checks); Tab completes folders |
| `/ws remove [root]` | active file's root, or the named root; last root refused |
| `/ws save [file]` | own file (current version) or a new file (+.vr-workspace); another existing file refused |
| `/ws open <file>` | `Workspace::from_file` → `open_workspace` (unsaved question) |
| `/ws recent [n]` | lists / opens entry n |
| `/theme synthwave\|dracula\|dark\|light` | session theme; Tab and the list complete names |
| `/wrap` | error "available after the soft wrap feature" (no soft wrap exists, decisions.md D? T20) |
| `/hidden`, `/ignored` | explorer toggles |
| `/help` | window shows "/" with every command |
| `/q`, `/q!` | quit with the guard / discard with the recovery copy |
