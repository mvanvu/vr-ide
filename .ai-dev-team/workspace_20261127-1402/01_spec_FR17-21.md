## SSH sessions (FR-25, D317) — security_sensitive: true
- AC-S1: Typing `ssh` in the command window offers one row per concrete `Host` alias in ~/.ssh/config (and files it `Include`s; wildcard / negated patterns skipped) plus recently used targets (most recent first, kept in vr-ide's state dir, at most 20), and accepts a typed target `[user@]host[:port]`. A malformed or option-like target (starting with `-`, containing whitespace or control characters) is refused with a notice; nothing is run.
- AC-S2: Choosing a target runs the system `ssh` (no shell in between; argv built from the parsed target, `--` before the destination) in a new terminal panel tab titled `ssh <target>`, with the panel shown, so host-key confirmation and password / passphrase prompts are answered there. vr-ide never reads, stores or logs what is typed into it.
- AC-S3: When authentication succeeds the tab goes full screen: it fills the whole window except one status row showing `SSH <target>` and the key back to the editor. Success is detected from ssh's LocalCommand (runs locally only after login) printing a per-session random marker that vr-ide consumes and never shows; output from the remote side cannot trigger it (marker unknown to the remote; a marker seen after the first is ignored). If the user's ssh config disables LocalCommand or the connection fails, the tab stays a normal panel tab and shows ssh's own messages.
- AC-S4: In full screen every key goes to the session except the keys a focused terminal keeps (ctrl+`, F1, ctrl+f7…f9 per D314/D316); ctrl+` returns to the editor layout with the session alive; choosing the session again (its tab, or `ssh` in the palette listing open sessions first) restores full screen; resize follows the window.
- AC-S5: When ssh exits (logout, disconnect, failure) full screen ends, the IDE layout returns and the tab shows the exit like other terminals ("[process exited N] — Enter to restart" reconnects to the same target).
- AC-S6: Several sessions can be open at once, one tab each; quitting vr-ide with live sessions asks like running terminals do (T26).
- AC-T1 (FR-26, D319): In every built-in theme the terminal panel's default background (cells a program leaves at the default colour) is visibly different from the editor's background, so the panel reads as a separate area; text in the default colour stays readable (≥ 7:1 where the theme has fixed colours); colours programs set themselves are unchanged; the SSH full-screen view (FR-25) uses the same terminal background.
