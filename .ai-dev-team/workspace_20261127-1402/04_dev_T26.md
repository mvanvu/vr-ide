## Behaviour / decisions
- Ask only when the terminal is Running and `shell_in_foreground()` is false. Exited terminal or idle shell: closes at once.
- Decision: "can't tell" (running, but tcgetpgrp unreadable, or a fake tab) is treated as asking, naming "A program" (safer than killing silently). Program name from /proc/<pgid>/comm, else "A program".
- Cancel is the default button (selected = 1), Esc = Cancel. The dialog carries the tab's pid; Close after the tab already went away does nothing.
- No key changes; the close stays a mouse-only 'x' (D291).
