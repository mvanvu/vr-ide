## API summary (plan M5 "Contracts")
- `Terminal::spawn(SpawnOptions{shell, args, cwd, env, cols, rows, scrollback}, notify: Notify) -> Result<Terminal, TermError>` — `notify: Arc<dyn Fn() + Send + Sync>` is the second argument.
- `write(&[u8])` (never blocks), `resize(cols, rows)`, `status() -> TermStatus{Running, Exited(i32)}`, `wait_exit(Duration)`, `kill()`, `snapshot(scroll_offset) -> Grid`, `pid()`, `size()`; consts `KILL_GRACE` (300 ms), `MAX_PENDING_INPUT` (1 MiB).
- `Grid{cols, rows, cells: Vec<Cell{ch: String, fg, bg, flags: CellFlags{bold, italic, underline, inverse, dim, hidden, strikeout, wide, wide_spacer}}>, cursor: Cursor{row, col, shape: CursorShape{Block, Underline, Beam, HollowBlock}, visible}, title, modes: Modes{alt_screen, mouse_reporting, mouse_drag, mouse_motion, sgr_mouse, bracketed_paste, app_cursor, app_keypad}, scrollback_len, scroll_offset}` + `cell(r, c)`, `row_text(r)`. `Color{Default, Indexed(u8), Rgb(u8,u8,u8)}`: named 0–15 → Indexed, dim variants → base index (DIM flag carries the dimming), fg/bg/cursor names → Default.
- `encode_key(KeyEvent{code: KeyCode, mods: Modifiers}, Modes)`, `encode_paste(&str, Modes)`, `encode_mouse(MouseEvent{kind: MouseKind, col, row, mods}, Modes)`; `KeyCode{Char, Enter, Tab, BackTab, Backspace, Esc, Left, Right, Up, Down, Home, End, PageUp, PageDown, Insert, Delete, F(u8)}`.
- Additive helpers (BASE-2): `wait_exit`, `pid`, `size`, `Grid::{cell, row_text}`, `Grid.scroll_offset`, `Modes.{mouse_drag, mouse_motion}`, `CellFlags.{hidden, strikeout}`, `TermError` variants (BadCwd, Pty, Spawn, BadSize, Closed, InputBacklog, Io).

## New states (round 0)
| State | Quit / drop | Error halfway | Input changes | Second request | Concurrent writer | Call never returns |
|---|---|---|---|---|---|---|
| reader thread (reads PTY, parses 4 KiB locked slices, Notify on the dirty false→true edge) | Drop sets `closed` (no Notify after drop), group killed, thread ends on EIO; joined ≤ 200 ms else detached | read error → thread ends; emulator stays readable | resize takes the same lock; later slices parse into the new size | snapshots raise `snapshot_waiting`, reader yields before each slice | one reader per terminal | grandchild that setsid()s and keeps the PTY → reader blocked; detached after JOIN_WAIT, Drop returns (fd + thread held until that process exits) |
| writer thread + input queue | Stop message; ends on write error; bounded join | write error → thread ends; `write` after exit → `Closed` | — | in-order queue | UI input and emulator replies (DSR/DA) share the queue | program never reads → queue capped at 1 MiB, `InputBacklog`, UI never blocks |
| waiter thread (waitid NOWAIT, reap under the status lock) | reaps after kill; bounded join | waitid error → reap via child.wait, code from it or -1 | — | `kill()` again → no-op | group signal vs reap serialised by the status lock → never signals a recycled pid | child in D state → kill returns after 2×KILL_GRACE, Drop after +200 ms, waiter detached |

| Notify coalescing (`dirty`) | none after Drop | — | — | snapshot re-arms; next output notifies once | — | callback must not block (documented on `Notify`) |
