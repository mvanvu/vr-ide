## API (crate vr-git, UI-free, thiserror)
- `Repo::discover(path)` / `discover_with(path, Options)` -> `Result<Option<Repo>>`: None for no git, a bare repo, a path inside .git, a repo git refuses (dubious ownership / safe.directory), or a work tree that is not an ancestor of the path (core.worktree elsewhere). `workdir()`, `git_dir()`, `common_dir()`, `relative(path)` (repo-relative, OutsideRepo otherwise; a symlink keeps its own name), `is_parent_repo_of(root)` (D298 "parent repo" label).
- `head() -> Head::{Branch{name, oid: Option (None = unborn)}, Detached{oid, short}}`; `ahead_behind() -> Option<AheadBehind{upstream, ahead, behind}>` (None: detached, unborn or no upstream).
- `status() -> Status{staged, unstaged: Vec<StatusEntry{path, orig_path, status}>}`, FileStatus = Modified/Added/Deleted/Renamed/Copied/TypeChanged/Untracked/Conflicted (untracked and conflicted are in `unstaged`, as in git gui).
- `diff_unstaged(path)` / `diff_staged(path)` -> `Option<FileDiff>`; `diff_commit(rev, Option<path>) -> Vec<FileDiff>` (first parent, empty tree for a root commit; renames followed when a path is given). `FileDiff{old_path, new_path, status, old_mode, new_mode, old_oid, new_oid (full, --full-index), similarity, binary, hunks: Vec<Hunk{old_start, old_len, new_start, new_len, header, lines: Vec<DiffLine{kind, old_line, new_line, text: Vec<u8>, no_newline}>}>}` — enough to build hunk/line patches in M7-2. Untracked file -> synthetic all-added diff; conflicted -> status Conflicted, no hunks.
- `log(limit, Option<path>) -> Vec<CommitSummary{oid, short, parents, author, committer: Signature{name, email, time}, summary, path}>` (`--follow`, the file's path in each commit); `commit(rev) -> CommitInfo{oid, parents, author, committer, message}` (+`summary()`); `resolve_commit(rev)` (rev-parse --verify --end-of-options rev^{commit}; refuses `--output=x` and the like).
- `blame(path)` / `blame_text(path, buffer)` -> `Option<Blame{commits: Vec<BlameCommit{oid, author, summary, uncommitted, boundary, filename, previous}>, lines: Vec<BlameLine{commit, orig_line, final_line}>}>` (`commit_of(line)`); None for an untracked file; a staged-only file is all uncommitted. blame_text sends the buffer on stdin (`--contents -`).
- `line_changes(path, buffer) -> Option<Vec<LineChange{kind: Added|Modified|Deleted, start, len}>>` against the index blob (None: untracked, conflicted, binary).
- `GitWorker::start(repo, notify)`, `request(Request) -> u64` (never blocks), `try_recv() -> Option<Response{id, request, result: Result<Arc<Reply>>}>`, `invalidate()`, `invalidate_path(p)`. Queued requests with the same kind+path are coalesced (older ones answered `Superseded`); results are cached by stats of HEAD, index, logs/HEAD, packed-refs, the current ref, FETCH_HEAD, the file and a hash of the buffer; full-SHA commit requests are cached as immutable. Worktree-only changes reach `Status` through invalidate()/invalidate_path() from the app's watcher. Use absolute paths in requests so invalidate_path matches.
- `Options{timeout 10 s, user_timeout 30 s, max_output 64 MiB, max_file 8 MiB, max_concurrent 2, env}`. `GitError::{GitNotFound, OutsideRepo, NotACommit, Timeout, TooLarge, Failed{cmd, code, stderr}, Parse, Io, Superseded}`.

## gix vs CLI (measured; decision: CLI only, logged in decisions.md as D? (M7-1))
Fixture: 50 001 files, 5 000 commits each changing one line of a 5 000-line file (renamed half way); load avg 11-25 on 8 shared cores.
| Operation | git CLI 2.43 | gix 0.91 (release, features blame+status+parallel) |
|---|---|---|
| status (one modified file) | 93 ms | 95-165 ms |
| blame 5k lines x 5k commits | 2.4-2.6 s | 2.4-3.0 s |
| build cost | 0 | +2 min 12 s release build, ~80 crates |
gix is not faster on either hot path, brings a large dependency tree, and its own filter/trust handling would need separate hardening (threat T2). The CLI covers everything (blame --contents, log --follow, porcelain v2 status). No dependency was added; the gix scratch project was deleted.
