## Precedence evidence
- Both grammars declare `Last`; the per-grammar test `every_grammar_declares_its_precedence_and_specific_patterns_win` has a case for each (xml: `php` in `<?php echo 1; ?>` is Keyword; dtd: `#PCDATA` is Type) and passes (final.log highlight: 26 passed).
- Flip probe: xml set to `First` in the table and in the test case, the test still passed, so no two xml patterns capture the same node with different classes (the PI target is a child of the `(PI) @embedded` node). Both cases are therefore marked `decides = false`. The probe was reverted (lib.rs and highlight.rs restored from copies).

## Reparse evidence
Both `Incremental`. `every_sample_equals_a_fresh_parse_full_seed_set` (release, ignored) reads every file of `tests/samples`, so it includes sample.xml and sample.dtd, and compares the spans after each seeded edit with a fresh parse: no difference. No separate raw tree-versus-tree probe was written.
