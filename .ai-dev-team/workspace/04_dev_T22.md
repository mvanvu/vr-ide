## Design calls (leader numbers them)
- D? (T22) Result list **below the box over the editor column**, not a side column: the list gets the full width for `line  text` and the editor stays visible above/below at every size (side column at 40 cols left the editor 16 cols, below 40 it covered it). The box = fields (1, or 2 with replace) + list sized to what it shows, from 3 rows up to two fifths of the editor; one editor row always stays. 80x24: list ≤ 8, editor ≥ 13; 40x12: list 3, editor 6. The explorer keeps its column next to the box. Consequences: the side-panel search (Side::Search, D118 width, D137 narrow hide) is gone; D137's "never type into a hidden editor" holds by construction (tests kept, reworded).
- D? (T22) Scope shown as a button-styled label at the start of the box's first row: ` File ` / ` Project ` (` F ` / ` P ` below 36 cols); selected-button colours while the box has the keys. The empty box lists the scope key and the syntax ("ctrl+f: search the project · /re/ regex · …/i ignore case · \/ a slash").
- D? (T22) Query syntax details: only `\/` is an escape (backslash dropped); every other backslash stays as typed (regex escapes keep working). An unclosed `/fo+` is literal until the closing slash. `/i` alone is an empty query. A selection seeds the box with slashes typed as `\/` (literal); a selection containing `\/` is not seeded.
- D? (T22) File scope lists one row per match (a line with two matches is listed twice) so the list, the count "i/N" and f3 step over the same items.
- D? (T22) ctrl+f from outside the box always opens File scope (Project with no file open); only ctrl+f while the box has the keys switches. Switching to Project with a query searches at once (unless those results are shown); switching back to File is refused while a project replace runs (the progress stays in view) and with no file open.
- D? (T22) Enter on a File-scope match / Project result gives the editor the keys in read mode and leaves the box open (highlights stay, f3/shift+f3 continue); in Project scope f3/shift+f3 step the project results. ctrl+r keeps the box's scope (box on the project → project replace).
- D? (T22) The project status ("3 results in 2 files", preview status) is on the box's first row; when it does not fit (narrow) it heads the list.
- D? (T22) Multi-root results get a root header row (`Row::Root`) before the first file of each root; Enter on it opens its first match.
- Kept as before (open user decisions untouched): D264 (legacy shift+f3 never arrives; walk shows count unchanged), D265 (Enter one / ctrl+a all in the replace field, Tab kept in the box).
