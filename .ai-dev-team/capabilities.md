# Capabilities — vr-ide

Greenfield: nothing reusable yet. Developers append one line per reusable piece they add
(`` `path` — what it does ``), grouped by crate.

## vr-core
- `crates/vr-core/src/text.rs` — `Buffer` (rope + selection + grouped undo, `version`, `revision`, `BufferOptions{tab_width,indent_unit}`), `display_col`, `char_at_display_col`, `char_to_pos`/`pos_to_char` (grapheme cols), `line_content_end`, `line_break_str`, `default_line_break`, `prev/next_grapheme_boundary`, `is_line_break`
- `crates/vr-core/src/selection.rs` — `Pos`, `Range`, `Selection` (sorted, merged, primary; `map`, `clamp`, `transform`)
- `crates/vr-core/src/transaction.rs` — `Change`, `Transaction` (`with_selection`), `normalize`, `apply_changes`, `invert_changes`, `map_pos`
- `crates/vr-core/src/history.rs` — `History` (`can_undo/can_redo/revision/break_group`), `Clock`, `SystemClock`, `ManualClock` (test time injection), `EditKind`, `GROUP_IDLE` = 1 s
- `crates/vr-core/src/motion.rs` — move_left/right/up/down, word_left/right, line_start (smart home), line_end, doc_start/end (`buf, extend`)
- `crates/vr-core/src/edit_ops.rs` — delete_line, duplicate_line, move_line_up/down, indent, outdent, toggle_comment(buf, token); each one undo step
- `crates/vr-core/src/document.rs` — `Document::{open(path, max_size_highlight), untitled, is_modified, save/save_overwrite/save_as -> Saved{other_hard_links}, disk_version() -> DiskVersion + save_overwrite_seen(&DiskVersion) (D64: the prompt's "keep mine" replaces only the disk version shown, else ChangedOnDisk), `DiskVersion::of_path(&Path)` (version of any path, absent counts) + `save_as_seen(&Path, &DiskVersion)` (FR-2: Save As replaces or creates only over the version seen, else ChangedOnDisk with path/state unchanged; own path = save with freshness check, also for `save_as`; `save_as` to another path takes `of_path` on entry and commits through `save_as_seen` (D89); non-regular targets are refused before any read), reload, check_disk, disk_stamp, set_own_writes}` (atomic temp+rename keeping mode/owner, writability probe, symlink write-through, ChangedOnDisk refusal re-checked right before rename), `DocError`, `DiskState`, `DiskStamp::of(path)`, `LineEnding::{detect, as_str}`, `Encoding`, `is_save_temp(path)`, `BINARY_SNIFF_LEN`
- `crates/vr-core/src/watch.rs` — `Watcher::new(Sender<FsEvent>)`, `watch(file|dir) -> Result`, `unwatch`, `own_writes()` (give to `Document::set_own_writes` once; own saves never echo back); `FsEvent::{Modified,Removed,Created,Renamed,Rescan,Error}` with caller paths, 200 ms `DEBOUNCE`; FR-4: `watch_dir(&Path) -> Result<(), WatchError>` / `unwatch_dir(&Path)` — one directory, its direct entries only, 1 inotify watch, no walk, ~1 ms per call (explorer: root + expanded folders)
- `crates/vr-core/src/safe_replace.rs` — `replace_if_unchanged(tmp, target, Checks{target_unchanged, holds_expected, holds_ours}, swap, seam: FnMut(Step)) -> Outcome::{Replaced, Changed, Kept{at,what,cause}}` (RENAME_EXCHANGE, content check of the file taken out, swap-back, and what comes out is deleted only when proven our own file with our own bytes, else kept as visible `<name>.vr-ide-conflict-PID-N`; state machine in the module doc), `create_if_absent` (NOREPLACE → hard link → check+rename), `exchange_files`, `kept_error`; used by `Document::save`/`save_overwrite_seen` and vr-search replace

## vr-search
